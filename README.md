# Building LLMs From Scratch

This repository contains implementations of language models built from scratch for educational purposes.

## Projects

### [Transformer From Scratch](transformer/)

A lightweight implementation of a GPT-style transformer for language modeling and text generation. The model is designed to be:

- Lightweight and runnable on Apple M2 chips
- Complete with all the standard transformer components
- Well-documented and easy to understand
- Trainable on simple text datasets for next token prediction

To get started with the transformer implementation, see the [Transformer README](transformer/README.md).
